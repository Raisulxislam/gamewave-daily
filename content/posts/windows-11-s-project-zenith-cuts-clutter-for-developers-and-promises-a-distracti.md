Microsoft has unveiled Project Zenith, a new Windows 11 experience built for developers, and the pitch is deceptively simple: boot up, and start coding. Dev tools arrive preinstalled, developer-first settings come pre-enabled, and the usual setup grind is cut out of the loop.

It's a seductive promise for anyone who has ever burned a weekend configuring a fresh machine before writing a single line of code.

## Project Zenith: a Windows that's ready before you are

Microsoft has spent years courting developers on Windows — Windows Subsystem for Linux, Dev Home and a relentless push on AI tooling all point that way — so Zenith reads as the next chapter of that campaign.

## 'Distraction-free' cuts both ways

A cleaner desktop and fewer interruptions sound lovely on paper. The open question is how much control developers keep — and whether "distraction-free" quietly becomes "stripped back." If Project Zenith delivers its promise without trimming flexibility, it could quickly become the default recommendation for a new dev machine.
